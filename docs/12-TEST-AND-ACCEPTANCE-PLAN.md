# Test and acceptance plan

Every confirmed requirement must have a traceable test ID and pass evidence. Tests: unit (pure policies), contract (plugins, config, CLI), integration (real disposable Restic, SQLite, storage), failure injection (SIGKILL, storage disconnect, crash at launch boundary), end-to-end (multi-destination workloads). Never use production repositories in certification.

## Mandatory acceptance gates

AT-001 primary fallback first usable secondary; AT-002 primary returns and catches up; AT-003 divergent union A/B/C; AT-004 normal replication fixed source; AT-005 same destination copies serialized across processes; AT-006 different destination copy concurrency when certified; AT-007 A10 pending replanning; AT-008 A11 post-launch failure blocks same-run replacement; AT-009 A12 launch boundary and uncertain launch; AT-010 copy exit 0 but unverified destination => failure; AT-011 incomplete enumeration never implies deletion; AT-012 wrong repo ID blocks; AT-013 wrong credentials isolated; AT-014 no automatic repo init/unlock; AT-015 retention after all transfers, common policy; AT-016 retention independent failures; AT-017 all pre-hooks attempted, cleanup after failed prep, no post; AT-018 job status independent of later shared storage release; AT-019 crashed owner does not yield unsafe claim reuse; AT-020 restored/corrupt DB fails closed; AT-021 external mounts preserved; AT-022 joined acquisition and last-waiter cancellation; AT-023 batch concurrency and precedence; AT-024 strict config unknown fields; AT-025 secrets absent from logs/argv/history; AT-026 Restic certification mandatory; AT-027 unsupported binary rejected; AT-028 canceled Restic terminated or conflicting ops blocked; AT-029 no automatic transfer retry; AT-030 snapshot lineage A→B→C verified; AT-031 independent similar metadata not false equivalent; AT-032 different chunker parameters warning; AT-033 required source missing aborts; AT-034 optional source missing reported; AT-035 dry-run no side effects; AT-036 admin replacement approval required; AT-037 process-launch crash at each journal boundary; AT-038 state migration rollback/recovery; AT-039 concurrent multi-repo atomic admission; AT-040 successful copies retained on partial convergence.

Each scenario must include preconditions, commands, expected DB events, expected CLI JSON/exit, and cleanup. `tests/acceptance/scenarios.yaml` is a machine-readable seed list. Release gate: all critical tests pass, no inconclusive Restic correctness tests, no unresolved unsafe recovery state.
